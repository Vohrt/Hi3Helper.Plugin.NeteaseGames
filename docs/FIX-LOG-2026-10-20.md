## 1. P0 —— 会损坏安装的缺陷（全部已修）

### P0-1 松散文件缺失时静默"成功"

**改前**：`NeteaseGamesUpdateApplier.cs` 发现松散文件变更只 `LogWarning`，随后照旧写 `pkgversion` 并
`return true` ⇒ Collapse 认为已最新，游戏缺文件。

**改后**：整文件重写为"**计划驱动**"的应用器：

- 松散文件是 `NeteaseGamesDownloadPlan` 的一等公民（`Kind = LooseFile`），与包/索引同批下载；
- **任何对象失败即 `return NeteaseGamesApplyResult.DownloadFailed/ApplyFailed`**，调用方抛异常，
  版本号绝不写入（`NeteaseGamesGameInstaller.RunAsync` → `throw new IOException(...)`）。

### P0-2 替换 `.mpk` 不换索引

**改后**：

- `NeteaseGamesGameInstaller.IsPackageIndex()` 区分 `.mpkinfo` 与分片，索引单列 `Kind = Index`；
- 落盘顺序固定为 **包 → 索引 → 松散文件 → 版本号**（`NeteaseGamesUpdateApplier.ApplyAsync`），
  版本号是唯一提交点，且通过临时文件原子写入（`WriteAtomic`）。

### P0-3 大小/进度语义三个来源不一致

**改前**：`GetGameSize(Install)` 返回**整个安装 78 GB**；`GetGameSize(Update)` 返回 mini-pack 1.39 GB
（与实际下载无关）；`GetGameDownloadedSize` 扫 `.collapse_download` 而实际写 `staging` ⇒ 恒为 0。

**改后**：

- 引入 `NeteaseGamesDownloadPlan` 作为**唯一事实来源**：`TotalSize` / `DownloadedSize` / 各 `Kind.Count`
  与进度回调全部从它取；
- 暂存目录统一为 `NeteaseGamesGameInstaller.StagingDirectoryName`（`.collapse_download`）；
- 进度回调同时更新 `StateCount`/`TotalStateToComplete`（不再是硬编码 1/1），并在下载开始前补发一次
  初始状态，避免"0 / N"冻结；
- 暂存文件名带序号前缀 ⇒ 同名包与索引不会互相覆盖。

## 2. P1 —— 安全与体验（全部已修）

### 2.1 TLS：5 处关闭校验 → 0 处

- 新增 `NeteaseGamesHttp.CreateClient(timeout)`，**所有**客户端统一由此创建（证书校验保持开启）。
- 删除 `NeteaseGamesDispatch.cs`（188 行）：它用 `ServerCertificateCustomValidationCallback = (_,_,_,_) => true`
  连接**远端下发的 IP**，是整个项目最大的 MITM 入口，且**无任何调用者**。

### 2.2 登录态：明文 → DPAPI + 用后即恢复

- `session.json`（明文 token）→ **`session.dat`（DPAPI `CurrentUser` 加密）**；
- `ApplyStoredSession()` 返回 `IDisposable`，启动器在 `using` 里注入环境变量，**游戏拉起后立即恢复原值**
  （不再把 token 永久留在长驻宿主进程里）。

### 2.3 进程匹配：按名字 → 按路径

- `GetGameProcesses()` 校验可执行文件路径是否位于安装目录/二进制目录内；
- `KillRunningGame` 失败（典型：未提权杀提权进程）现在返回 `false` 并 `LogWarning`，
  **不再静默假装成功**；
- 删除死方法 `RestorePath()`。

### 2.4 启动性能：`InitAsync` 无限等待 → 5 秒上限

- `NeteaseGamesGameManager.StartupProbeTimeout = 5s`，`CancellationTokenSource.CreateLinkedTokenSource` 限时；
- 远端探测改为"**只有拿到权威版本号才标记完成**"（失败下次重试，不再一次失败永久静默）；
- `ReadPatchList` 增加按 `(mtime, size)` 的解析缓存（17 MB / 23 万条只解一次）。

### 2.5 其它

- 卸载前校验目标确实是游戏目录（否则拒绝删除），避免误删启动器目录；
- 下载失败后**删除损坏的暂存文件**再重试（原来会追加到坏文件上，必然反复校验失败）；
- 引擎载荷由 `ReadAsByteArrayAsync`（整文件进内存，含 142 MB 的 `libcef.dll`）改为**走同一套
  落盘下载器**（流式 + 续传 + MD5 可选校验）；
- 远端路径全部经 `ResolveTargetPath` 校验，**拒绝逃出安装目录的路径**（如 `..\..\windows\...`）。
